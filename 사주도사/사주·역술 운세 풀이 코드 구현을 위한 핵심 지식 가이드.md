# 사주·역술 운세 풀이 코드 구현을 위한 핵심 지식 가이드

## 1. 사주(四柱)의 개념과 구조

사주팔자(四柱八字)는 태어난 **연(年)·월(月)·일(日)·시(時)** 네 기둥(四柱)에 각각 천간(天干)과 지지(地支)를 붙여 총 8글자(八字)로 구성하는 체계다. 이 여덟 글자의 조합이 사람의 타고난 성향과 운명의 틀을 이루며, 여기에 대운(大運)·세운(歲運)·월운(月運)이 덧붙어 시간에 따른 운세 변화를 해석한다.[^1][^2]

사주명리에서 **일주(日柱)의 천간, 즉 일간(日干)이 "나 자신"**을 나타내며, 나머지 7글자는 모두 일간과의 관계로 의미가 정해진다. 따라서 코드 구현 시 모든 해석의 기준점은 일간이 된다.[^3][^1]

## 3. 사주 세우기(四柱 立命式) 알고리즘

### 3.1 년주(年柱) 계산

- **기준**: 입춘(立春, 양력 2월 4일경) — 음력 1월 1일이 아니다[^5]
- 입춘 이전 출생자는 전년도 년주를 사용한다[^5]

```python
def get_year_ju(year, month, day, hour, minute, junggi_db):
    """
    junggi_db: {year: {"입춘": datetime}} 형태의 절기 DB
    """
    ipchun = junggi_db[year]["입춘"]
    birth_dt = datetime(year, month, day, hour, minute)
    if birth_dt < ipchun:
        effective_year = year - 1
    else:
        effective_year = year
    # 1984년 = 갑자년(0번) 기준으로 계산
    idx = (effective_year - 1984) % 60
    return GAPJA_60[idx]
```

### 3.2 월주(月柱) 계산

월주는 **절기(節氣)** 기준으로 결정되며, 음력 날짜나 양력 월과 무관하다. 12절(節)이 각 월의 시작점이 된다.[^6][^7]

| 절기(節) | 입절 시점(대략) | 월지(月支) | 월 |
|---------|--------------|-----------|---|
| 입춘(立春) | 2월 4일경 | 寅(인) | 1월 |
| 경칩(驚蟄) | 3월 5일경 | 卯(묘) | 2월 |
| 청명(淸明) | 4월 5일경 | 辰(진) | 3월 |
| 입하(立夏) | 5월 6일경 | 巳(사) | 4월 |
| 망종(芒種) | 6월 6일경 | 午(오) | 5월 |
| 소서(小暑) | 7월 7일경 | 未(미) | 6월 |
| 입추(立秋) | 8월 7일경 | 申(신) | 7월 |
| 백로(白露) | 9월 8일경 | 酉(유) | 8월 |
| 한로(寒露) | 10월 8일경 | 戌(술) | 9월 |
| 입동(立冬) | 11월 7일경 | 亥(해) | 10월 |
| 대설(大雪) | 12월 7일경 | 子(자) | 11월 |
| 소한(小寒) | 1월 5일경 | 丑(축) | 12월 |

월간(月干)은 **년간오호둔(年干五虎遁)** 법칙으로 결정된다:[^5]

| 년간 | 인월(1월) 월간 시작 |
|------|------------------|
| 甲/己 | 丙寅 (병인) |
| 乙/庚 | 戊寅 (무인) |
| 丙/辛 | 庚寅 (경인) |
| 丁/壬 | 壬寅 (임인) |
| 戊/癸 | 甲寅 (갑인) |

```python
# 년간 인덱스 → 인월 월간 인덱스 매핑
WOLGAN_START = {0: 2, 1: 4, 2: 6, 3: 8, 4: 0,  # 甲乙丙丁戊
                5: 2, 6: 4, 7: 6, 8: 8, 9: 0}   # 己庚辛壬癸

def get_month_ju(year_gan_idx, month_jiji_idx):
    start_gan = WOLGAN_START[year_gan_idx]
    # 인(寅)=0번 기준으로 몇 번째 월인지 계산
    month_offset = (month_jiji_idx - 2) % 12  # 寅=2
    gan_idx = (start_gan + month_offset) % 10
    return (CHEONGAN[gan_idx], JIJI[month_jiji_idx])
```

### 3.3 일주(日柱) 계산

일주는 1900년 1월 1일(갑술일, 60갑자 10번)을 기준으로 경과 날짜를 60으로 나눈 나머지로 계산한다.[^3]

```python
from datetime import datetime

BASE_DATE = datetime(1900, 1, 1)   # 갑술(甲戌)일 = 60갑자 index 10
BASE_IDX = 10

def get_day_ju(year, month, day):
    target = datetime(year, month, day)
    delta = (target - BASE_DATE).days
    idx = (BASE_IDX + delta) % 60
    gan_idx = idx % 10
    ji_idx = idx % 12
    return (CHEONGAN[gan_idx], JIJI[ji_idx])
```

### 3.4 시주(時柱) 계산

시주는 **시두법(時頭法)** — 일간오자둔(日干五子遁) 법칙으로 결정된다:[^5]

| 일간 | 자시(子時) 시간 시작 |
|------|------------------|
| 甲/己 | 甲子 (갑자) |
| 乙/庚 | 丙子 (병자) |
| 丙/辛 | 戊子 (무자) |
| 丁/壬 | 庚子 (경자) |
| 戊/癸 | 壬子 (임자) |

```python
SIGAN_START = {0: 0, 1: 2, 2: 4, 3: 6, 4: 8,   # 甲乙丙丁戊
               5: 0, 6: 2, 7: 4, 8: 6, 9: 8}    # 己庚辛壬癸

# 시간(0~23) → 지지 인덱스 변환
def hour_to_jiji(hour):
    # 23:30~01:29 = 子, 01:30~03:29 = 丑 ...
    return ((hour + 1) // 2) % 12

def get_time_ju(day_gan_idx, hour):
    jiji_idx = hour_to_jiji(hour)
    start_gan = SIGAN_START[day_gan_idx]
    gan_idx = (start_gan + jiji_idx) % 10
    return (CHEONGAN[gan_idx], JIJI[jiji_idx])
```

> **주의**: 진태양시(眞太陽時) 보정이 필요하다. 한국 표준시(UTC+9)는 경도 135°를 기준으로 하므로, 실제 출생지 경도에 따라 최대 ±30분 편차가 생긴다.[^8]

## 4. 오행(五行) 상생·상극 로직

오행은 木·火·土·金·水 다섯 기운의 상호작용으로 사주 해석의 핵심 엔진이다.[^9][^10]

### 상생(相生): 돕는 관계
木 → 火 → 土 → 金 → 水 → 木 (순환)[^10][^11]

### 상극(相剋): 억제하는 관계
木 → 土 → 水 → 火 → 金 → 木 (순환)[^11][^10]

```python
OHAENG = ["木", "火", "土", "金", "水"]
OHAENG_IDX = {o: i for i, o in enumerate(OHAENG)}

def is_sangsaeng(a, b):
    """a가 b를 생(生)하는가?"""
    i = OHAENG_IDX[a]
    return OHAENG[(i + 1) % 5] == b

def is_sangguk(a, b):
    """a가 b를 극(剋)하는가?"""
    # 木剋土, 土剋水, 水剋火, 火剋金, 金剋木
    guk_map = {"木":"土","土":"水","水":"火","火":"金","金":"木"}
    return guk_map.get(a) == b
```

## 6. 십성(十星) / 육친(六親) 계산

십성은 일간을 기준으로 나머지 7글자와의 **오행 관계 + 음양 동이(同異)** 로 결정된다. 코드 구현에서 가장 핵심적인 해석 레이어다.[^16]

### 십성 판단 규칙표

| 십성 | 오행 관계 (일간 기준) | 음양 |
|------|---------------------|------|
| 비견(比肩) | 동일 오행 | 같음 |
| 겁재(劫財) | 동일 오행 | 다름 |
| 식신(食神) | 내가 생(生)하는 오행 | 같음 |
| 상관(傷官) | 내가 생(生)하는 오행 | 다름 |
| 편재(偏財) | 내가 극(剋)하는 오행 | 같음 |
| 정재(正財) | 내가 극(剋)하는 오행 | 다름 |
| 편관(偏官) | 나를 극(剋)하는 오행 | 같음 |
| 정관(正官) | 나를 극(剋)하는 오행 | 다름 |
| 편인(偏印) | 나를 생(生)하는 오행 | 같음 |
| 정인(正印) | 나를 생(生)하는 오행 | 다름 |

```python
def get_sibsung(ilgan, target_gan):
    """일간과 대상 천간의 십성 계산"""
    il_oh = OHAENG_CG[CHEONGAN.index(ilgan)]
    tg_oh = OHAENG_CG[CHEONGAN.index(target_gan)]
    il_uy = UMYANG_CG[CHEONGAN.index(ilgan)]
    tg_uy = UMYANG_CG[CHEONGAN.index(target_gan)]
    same_uy = (il_uy == tg_uy)

    if il_oh == tg_oh:
        return "비견" if same_uy else "겁재"
    elif OHAENG[(OHAENG_IDX[il_oh] + 1) % 5] == tg_oh:   # 내가 생
        return "식신" if same_uy else "상관"
    elif is_sangguk(il_oh, tg_oh):                         # 내가 극
        return "편재" if same_uy else "정재"
    elif is_sangguk(tg_oh, il_oh):                         # 나를 극
        return "편관" if same_uy else "정관"
    elif OHAENG[(OHAENG_IDX[tg_oh] + 1) % 5] == il_oh:   # 나를 생
        return "편인" if same_uy else "정인"
    return "unknown"
```

지지의 십성은 지장간의 **본기(정기)** 오행을 사용하거나, 지장간 전체를 고려해 판단한다.[^17][^16]

## 7. 합·충·형·해·파(合沖刑害破) 작용

천간과 지지 사이의 특수 상호작용으로, 운세의 변화(동(動))를 일으키는 핵심 요소다.[^18]

### 7.1 천간합(天干合) — 합화(合化)

| 합 | 변화 오행 |
|----|---------|
| 甲+己 | 土 |
| 乙+庚 | 金 |
| 丙+辛 | 水 |
| 丁+壬 | 木 |
| 戊+癸 | 火 |

### 7.2 지지합(地支合) — 육합(六合)

子+丑=土, 寅+亥=木, 卯+戌=火, 辰+酉=金, 巳+申=水, 午+未=土

### 7.3 삼합(三合)

- 寅午戌 → 火局
- 亥卯未 → 木局
- 申子辰 → 水局
- 巳酉丑 → 金局

### 7.4 방합(方合) — 같은 계절 3지지

- 寅卯辰 → 봄 木局
- 巳午未 → 여름 火局
- 申酉戌 → 가을 金局
- 亥子丑 → 겨울 水局

### 7.5 지지충(地支沖) — 6충

子↔午, 丑↔未, 寅↔申, 卯↔酉, 辰↔戌, 巳↔亥[^19]

```python
CHUNG_PAIRS = {(0,6),(1,7),(2,8),(3,9),(4,10),(5,11)}  # 지지 인덱스 쌍

def is_jiji_chung(a_idx, b_idx):
    return (min(a_idx,b_idx), max(a_idx,b_idx)) in {
        (min(x,y), max(x,y)) for x,y in CHUNG_PAIRS}
```

## 8. 대운(大運) 계산

대운은 10년 단위로 운세의 큰 흐름을 나타낸다. 월주를 기준으로 순행 또는 역행한다.[^20]

### 8.1 순행/역행 결정

| 년간 | 남성 | 여성 |
|------|------|------|
| 양년(甲丙戊庚壬) | 순행 | 역행 |
| 음년(乙丁己辛癸) | 역행 | 순행 |

### 8.2 대운수(大運數) 계산

1. **순행**: 출생일 → 다음 절기까지 날수 계산
2. **역행**: 출생일 → 이전 절기까지 날수 계산
3. 날수 ÷ 3 = 대운 시작 나이 (반올림)[^21][^22]

> 원리: 30일(1개월) = 대운 10년에 대응, 3일 ≈ 1년[^23]

```python
def calculate_daewoon(birth_date, gender, year_gan_idx, month_jiji_idx, junggi_db):
    umyang = UMYANG_CG[year_gan_idx]
    # 양남·음녀 = 순행, 음남·양녀 = 역행
    if (gender == "남" and umyang == 1) or (gender == "여" and umyang == 0):
        forward = True
    else:
        forward = False

    # 절기 날짜 검색 (junggi_db에서 다음/이전 절기 찾기)
    if forward:
        next_junggi = get_next_junggi(birth_date, junggi_db)
        delta_days = (next_junggi - birth_date).days
    else:
        prev_junggi = get_prev_junggi(birth_date, junggi_db)
        delta_days = (birth_date - prev_junggi).days

    daewoon_start_age = round(delta_days / 3)

    # 대운 간지: 월주에서 순/역으로 60갑자 순회
    month_gapja_idx = get_gapja_idx(month_jiji_idx)  # 월주의 60갑자 인덱스
    daewoon_list = []
    for i in range(1, 9):  # 8대운 (80년)
        if forward:
            idx = (month_gapja_idx + i) % 60
        else:
            idx = (month_gapja_idx - i) % 60
        daewoon_list.append({
            "age": daewoon_start_age + (i - 1) * 10,
            "gapja": GAPJA_60[idx]
        })
    return daewoon_list
```

## 9. 세운(歲運)·월운(月運)·일운(日運)

세운과 월운은 대운이라는 큰 흐름 안에서 구체적인 타이밍을 결정한다.[^2]

| 구분 | 주기 | 영향력 | 결정 방법 |
|------|------|-------|---------|
| 대운(大運) | 10년 | ~70~80% | 월주 기준 순/역행 |
| 세운(歲運) | 1년 | ~15% | 해당 연도의 년주(입춘 기준) |
| 월운(月運) | 1개월 | ~5% | 해당 월의 월주(절기 기준) |
| 일운(日運) | 1일 | 미미 | 해당 날의 일주 |

- 세운은 모든 사람에게 동일한 간지로 적용되지만, 개인 사주와의 관계에 따라 영향이 다르게 나타난다.[^2]
- 코드로는 단순히 해당 연월일의 년주·월주·일주를 계산한 뒤, 원국(原局)의 각 글자와 상생·상극·합·충 관계를 분석하면 된다.

## 10. 격국(格局)과 용신(用神)

격국과 용신은 사주 해석의 가장 고급 레이어로, 운세 풀이의 핵심 판단 로직이다.[^24][^25]

### 10.1 격국(格局) 결정 순서

1. **월지(月支) 확인**: 월지의 지장간 중 **정기(본기)** 를 파악한다
2. **천간 투출(透出) 확인**: 월지 정기가 천간(사주 8글자의 천간 4개)에 나타났는지 확인한다
3. **격 결정**: 투출된 천간의 일간 대비 십성이 격이 된다 (예: 정기가 일간 대비 정관이면 "정관격")[^26][^27]

> 월지 정기가 투출되지 않으면 중기, 여기 순서로 확인한다.[^25][^27]

### 10.2 용신(用神) 결정 원리

용신은 "일간이 필요로 하는 가장 중요한 오행"으로, 사주 길흉 판단의 핵심이다.[^26]

- **신강(身强) 사주**: 일간의 힘이 강하면 → 극(剋)하거나 설기(泄氣)하는 오행이 용신
- **신약(身弱) 사주**: 일간의 힘이 약하면 → 생(生)해주는 오행이 용신[^25][^26]

신강·신약 판단 기준:
- **득령(得令)**: 월지가 일간 오행을 돕는가?
- **득지(得地)**: 지지 전체가 일간을 생하거나 같은 오행인가?
- **득세(得勢)**: 천간 전체 세력이 일간 편인가?[^26]

### 구축 방법

**방법 A: ephem 라이브러리 활용 (태양 황경 계산)**

```python
import ephem
from datetime import datetime

def get_solar_term_date(year, longitude_deg):
    """태양 황경이 특정 값(longitude_deg)에 도달하는 날짜 계산"""
    sun = ephem.Sun()
    # 황경 315° = 입춘, 345° = 경칩, ...
    # 0°부터 15° 간격으로 24절기
    target = ephem.degrees(f"{longitude_deg}:00:00")
    date = ephem.Date(f"{year}/1/1")
    while True:
        sun.compute(date)
        if sun.hlong >= target:
            break
        date += 1
    return ephem.Date(date).datetime()

# 24절기 황경값
```

## 13. 구현 시 주요 주의사항

1. **절기 시각의 정밀도**: 절입일의 정확한 시·분까지 반영해야 경계 출생자의 월주가 달라진다.[^6]
